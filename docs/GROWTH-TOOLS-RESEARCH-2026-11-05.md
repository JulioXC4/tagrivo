## MVP implementado y límites publicados

Ruta canónica: `/tools/shipping-label-cropper/`. Una página útil, sin nuevas guías duplicadas. Enlaces desde Tools, Label Preview, Troubleshooter y la guía de tamaño; enlaces contextuales a guías, Finder, Compare y calculadora. WebApplication describe únicamente funciones visibles, sin ratings ni promesas de posicionamiento.

- Entrada PDF local hasta 20 MB y 50 páginas; una página seleccionada por exportación. Rectángulo visual/táctil y porcentajes para teclado. Presets de hoja completa/mitades, selección de página, giro de salida.
- Salida exacta 288×432 puntos PDF (101.6×152.4 mm), ajuste proporcional y centrado. Mantiene contenido original vectorial; no promete arreglar un raster borroso ni certificar lectura de un código.
- PDF.js 6.5.438 (Apache-2.0) para preview, pdf-lib 1.17.1 (MIT) para exportación. Carga diferida al elegir un archivo; worker, CMaps, fuentes y decodificadores propios, sin CDN ni servicio de pago. Recursos/avisos de licencia generados en predev/prebuild; no se versiona node_modules ni recursos temporales.
- Sin endpoint de subida; sin nombre/contenido/coordenadas en GA4, URL, localStorage o eventos. La medición de visitas existente continúa tras consentimiento. No se añade publicidad propia ni otra herramienta de analítica.
- PDFs cifrados o páginas con anotaciones/formularios no se aceptan; se explica cómo recuperar con original aplanado. Recorte no es redacción: contenido oculto puede permanecer embebido. No se genera ni valida franqueo.
- Documentación técnica: [PDF.js](https://mozilla.github.io/pdf.js/examples/), [API PDF.js](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html), [pdf-lib embedPage](https://pdf-lib.js.org/docs/api/classes/pdfdocument#embedpage) y [drawPage](https://pdf-lib.js.org/docs/api/classes/pdfpage#drawpage).

## Cómo medir sin inventar resultados

Guardar una línea base del día de publicación. En Bing Search Performance y Search Console, filtrar la nueva ruta, Estados Unidos, web y comparar ventanas de 28 días cuando exista suficiente información. Separar impresiones, clics, consultas y páginas indexadas; no confundir Keyword Research con tráfico de Tagrivo. Revisar “crop shipping label”, “4x6 PDF”, “label cropper” y variantes que realmente aparezcan.

GA4: filtrar landing page / page path y source/medium bajo el consentimiento actual. No se envían documentos ni valores de recorte ni se promete contabilizar usuarios que rechacen medición. Para valorar la tarea, complementar con comentarios voluntarios; el MVP no instala seguimiento de archivos. IndexNow notificará cambios reales solo después de que el commit se publique correctamente, usando el flujo existente. Aceptación de IndexNow no significa indexación.

Para mejorar este ranking más adelante, el propietario puede exportar Bing Keyword Research US/12 meses para las consultas de la tabla y los informes de rendimiento por página. No es requisito para usar el MVP, pero sí para afirmar demanda cuantificada y priorizar otra inversión. Si faltan señales, mejorar la herramienta existente antes de crear las otras tres.
