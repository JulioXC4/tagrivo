## Solapamientos y canibalización

Sin consultas y posiciones por URL en Bing Search Performance/GSC, no se puede diagnosticar canibalización efectiva. Se detectaron estos **riesgos de solapamiento**, tratados sin nuevas páginas ni redirects:

- Portada = especialidad editorial; catálogo = tres modelos; guía general = criterios; Compare = tabla interactiva. No convertir las cuatro en una lista “best thermal label printer”. Los H1 de marca en hero y herramientas se conservan; título SEO y contexto cercano explican la función sin texto oculto.
- Guía marketplace = proceso completo; Etsy sizing = problema de impresión; Shopify models = lista oficial y modelo exacto. Las páginas enlazan la respuesta especializada en lugar de duplicarla.
- Cost guide = explicación y supuestos; calculator = cálculo. La calculadora no pretende ser otro artículo de costes.
- Mac/Windows = OS y CPU; móvil = app/PDF; conexiones = protocolo. Se mantiene el cruce entre guías, pero se evita tratarlas como la misma compatibilidad.
- Rollo/MUNBYN y Rollo/Brother = decisiones diferentes. Las fichas conservan su intención de un único modelo y la herramienta compara campos.

Para comprobarlo con datos: filtrar una consulta en Bing/GSC y comparar la dimensión Página durante periodos equivalentes. Dos páginas con impresiones para un término no bastan para declarar canibalización. Si alternan para la misma intención y ninguna responde mejor, revisar el contenido antes de plantear una consolidación; no actuar solo por una oscilación inicial.

## Cómo medir esta edición

Anotar la fecha y el commit publicados en los informes. No rellenar impresiones o visitas con datos de Keyword Research.

| Sistema | Revisión | Interpretación correcta |
|---|---|---|
| Bing Search Performance | Periodos equivalentes, filtro US si está disponible, consulta y página: impresiones, clics, CTR y posición reportada | Es el rendimiento real de Tagrivo. Comparar 28 días antes/después cuando ambos periodos tengan datos; mientras tanto revisar semanalmente descubrimiento e impresiones sin concluir por muestras pequeñas. |
| Google Search Console | Rendimiento → Web, país Estados Unidos, consulta/página; Indexación y lectura del sitemap por separado | Si una URL no tiene impresiones, revisar indexación y descubrimiento antes de atribuir el resultado al título. CTR = clics / impresiones con denominador mayor que cero; sin objetivo inventado. |
| GA4 | Adquisición de tráfico y página de destino; tráfico orgánico Bing/Google cuando el origen esté disponible | Solo visitas consentidas y no bloqueadas. No equiparar sesiones a clics GSC/Bing ni asumir atribución completa. |
| GA4 eventos | `amazon_affiliate_click`, `printer_finder_complete`, `comparison_used`, `cost_calculator_used` por página | Señales de interacción; no ventas. Para contexto, comparar eventos por sesiones del mismo filtro/periodo, sin llamarlo tasa de compradores. |
| Amazon Associates | Clics, pedidos/artículos y comisiones de `tagrivo-20` | Datos comerciales agregados de Amazon, con devoluciones/ajustes. No atribuir una venta individual a una keyword o sesión GA4 sin evidencia. |
| IndexNow / Actions | URL modificadas y respuesta HTTP; Bing Insights cuando se actualice | Recepción no equivale a indexación. Debe notificarse el diferencial real después de producción, no reenviar las 24 páginas por rutina. |

No se añaden herramientas, cookies, UTMs arbitrarios ni eventos de analítica para esta edición. No se modifican políticas, datos legales o consentimiento.
